# Explanation

These pages explain why Nasute works the way it does, and they are written for the moment when you want to know whether to trust a number rather than when you want to do a job. You can read them in any order, though the page on the statistics is the one that most changes how you read a score.

- [The statistics](statistics.md): error bars, comparing two runs, and how many questions you need, following Miller (2024).
- [Why the judge says yes or no](why-the-judge-says-yes-or-no.md): the judge never gives a score.
- [How errors count](how-errors-count.md): system errors, judge errors and stopped runs.
- [The judge-check](the-judge-check.md): testing the judge, with Accuracy and Cohen's kappa.
- [Independence](independence.md): why one question must not influence another.
- [Limits](limits.md): where Nasute falls short, including the ceiling effect.

# How-to guides

These guides each cover one job, and they assume you have already worked through the [Quick start](../tutorial.md) or know the basics from [How Nasute works](../how-nasute-works.md). Open the one that matches what you want to do and follow the steps from the top.

- [Add a target](add-a-target.md): point Nasute at an HTTP endpoint or a Python function.
- [Write and version a dataset](write-a-dataset.md): write the questions and change them safely.
- [Import questions from a CSV](import-a-csv.md): write them in a spreadsheet instead.
- [Tag questions and set difficulty](tag-questions.md): get scores by topic and by easy, medium and hard.
- [Use profiles](use-profiles.md): choose between a quick look and a careful run.
- [Compare two models on the same questions](compare-runs.md)
- [Baselines and labels](baselines-and-labels.md): pick the run to measure against and name your runs.
- [Read a run page](read-a-run-page.md): check the judge's work on one question.
- [Export a run](export-a-run.md): take its scores and answers into a spreadsheet.
- [Run a deep test overnight on a shared machine](run-overnight.md): do it without overheating the processor.
- [Use a cloud judge](use-a-cloud-judge.md): let a hosted model mark the answers.
- [Check the judge, and add judge items](judge-check.md)
